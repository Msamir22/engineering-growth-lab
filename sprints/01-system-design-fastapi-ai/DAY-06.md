# Day 06 — Timeouts + Retries + Failure Mapping

**Budget:** ~4 hours

## Study (~30–40 min)
Timeouts; transient failures; exponential backoff/jitter; retry storms; circuit breaker concept.

Use primary/official docs for version-sensitive behavior.

## Design (~45–60 min)
Before coding, write assumptions and the smallest design that meets today's requirement.

## Hands-on (~90–120 min)
Bound timeout/retry; tests for timeout/429/5xx/malformed; update failure modes.

## Verify + Document (~30–45 min)
- run relevant tests/checks;
- record evidence;
- commit first attempt;
- request tutor review;
- apply verified corrections.

## Exit Criteria
Retry budget and total wait are bounded and explainable.
