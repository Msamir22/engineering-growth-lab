# Day 11 — AI Evaluation

**Budget:** ~4 hours

## Study (~30–40 min)
Regression corpora; field metrics; negative cases; reproducibility.

Use primary/official docs for version-sensitive behavior.

## Design (~45–60 min)
Before coding, write assumptions and the smallest design that meets today's requirement.

## Hands-on (~90–120 min)
~30 synthetic cases; evaluator; baseline metrics.

## Verify + Document (~30–45 min)
- run relevant tests/checks;
- record evidence;
- commit first attempt;
- request tutor review;
- apply verified corrections.

## Exit Criteria
Model/provider changes can be compared reproducibly.

## Completion
- [ ] first attempt before asking AI for final solution
- [ ] tutor/reviewer feedback
- [ ] verified corrections
- [ ] commit/evidence recorded
- [ ] PROGRESS.md updated
