# Day 05 — Real AI Provider + Structured Output

**Budget:** ~4 hours

## Study (~30–40 min)
Provider abstraction; untrusted model output; structured validation; secret config.

Use primary/official docs for version-sensitive behavior.

## Design (~45–60 min)
Before coding, write assumptions and the smallest design that meets today's requirement.

## Hands-on (~90–120 min)
Implement one real provider; validate response; domain map; mocked adapter tests.

## Verify + Document (~30–45 min)
- run relevant tests/checks;
- record evidence;
- commit first attempt;
- request tutor review;
- apply verified corrections.

## Exit Criteria
Malformed model output cannot silently pass; no secret committed.

## Completion
- [ ] first attempt before asking AI for final solution
- [ ] tutor/reviewer feedback
- [ ] verified corrections
- [ ] commit/evidence recorded
- [ ] PROGRESS.md updated
