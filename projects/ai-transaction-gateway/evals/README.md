# AI Evaluation

Day 11 builds a reproducible synthetic regression corpus.

Target ~30 cases:
- English;
- Arabic;
- Egyptian Arabic;
- mixed language;
- multiple transactions;
- missing currency;
- relative/explicit dates;
- merchant;
- ambiguous input;
- non-financial input.

Initial metrics:
- schema validity;
- transaction count;
- amount;
- currency;
- type;
- merchant/counterparty;
- date where deterministic.

No real personal SMS/bank data.
